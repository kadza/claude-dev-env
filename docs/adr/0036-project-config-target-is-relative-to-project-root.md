# Project config target is a path relative to the project root

`--project-config-target <rel-path>` places the `.claude`/`CLAUDE.md` symlinks at `<rel-path>/.claude` and `<rel-path>/CLAUDE.md` instead of the project root, for a repo that nests the actual project in a subdirectory (e.g. a monorepo's `api/`) — the working directory Claude Code is actually run from isn't always the repo root. It requires `--project-config` and is rejected outright if absolute or containing `..`, since it's spliced directly into a path under the project directory with no other sanitization. Rejected: inferring the subdirectory automatically (e.g. by searching for a `package.json`/`pyproject.toml`) — repos can nest their real project anywhere, or have several, so guessing would be fragile; an explicit flag is unambiguous and matches how `--project-config` itself already requires an explicit path rather than guessing.
